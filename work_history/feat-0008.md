## One deliberate duplication

The `LyricBlock` `[section]`/`{ }` rendering is re-implemented in
`IdeaPage` rather than shared. Extracting it would mean editing
`SketchbookMock.tsx`, whose markup is pinned by `SketchbookView.test.tsx`
*and* `app/e2e/stats-and-sketchbook.spec.ts`. Duplication bought to protect
the mock. Now that the mock has a real browser gate, extracting it is a
safe follow-up — but making this PR the one that first moves it would have
been the worse trade.

## Friction log

- **The ticket was implemented and fully gated during a homelab outage.**
  `gitea`, `caddy`, `caddy-1`, `geekom1`, `k3s-node`, `k3s-pve05`,
  `pve-05`, `pihole`, `pm`, `research-lab` and `octoprint-pi` all dropped
  off the tailnet within ~10 minutes. `.lab` names stopped resolving too,
  since `pihole` *is* the resolver, so there was no LAN fallback. The
  commit sat unpushed on the laptop until the forge returned. It was
  deliberately not pushed to the GitHub mirror: work branches never go to
  the public showcase remote, and an outage does not suspend that rule.
  The loop terminated rather than polling for the homelab — correctly, per
  progress-or-death.
- **My first deployed-check script failed 6/9, and every one of those
  failures was the script, not the app.** Worth recording because the
  failure mode is seductive:
  - `check('live sketchbook rendered', noSketchGridPresent)` asserted only
    the *absence* of the mock, so it passed while the nav click had
    silently not landed and the page was still Library. An assertion that
    can only fail one way is barely an assertion.
  - Chip text compared with `=== 'test'` against `.chip` innerText, which
    is `"TEST\n×"` — CSS `text-transform` plus the remove button. The tag
    had persisted correctly the whole time.
  - A fixed `waitForTimeout(4000)` after upload beat the panel's refetch,
    so the asset was reported missing after it had already landed
    server-side (`POST 201`).
  The lesson is the one FX2's own timing claim taught earlier the same day:
  **one red result is a hypothesis, not a finding.** Diagnose before
  reporting — here, `curl`ing the deployed bundle for `attachments-panel`
  proved the deploy had rolled and moved the suspicion to the right place.
- Two identical `tone.opus` assets now sit on idea #1 of the dev slot, from
  two check runs. Content-addressed storage dedups the *bytes* but still
  writes a second asset row. Harmless test data on a dev slot; noted rather
  than cleaned so the next reader isn't puzzled by it.
