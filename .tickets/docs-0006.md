## Notes

- **Method.** Thirteen adversarial lens finders (six F1: empirical Verovio,
  model shape, anchor contract, persistence/backend, consumer demands,
  editor forward-compat; seven F2: pedagogue, generator feasibility, scorer
  operational definitions, matcher/attribution, psychometrics, cross-doc,
  musicality/product) produced 332 findings; the two-refuter verification
  stage hit the session limit after 3 findings, so the synthesis (this
  branch) was done by hand against the raw findings, with every empirical
  Verovio claim re-run locally before it was written into a doc. A final
  six-critic pass (cross-doc consistency, SC1/SR1 implementability,
  pedagogy/preset satisfiability, citation audit, grooming/routing audit)
  ran over the amended docs before the PR.
- **Evidence.** `docs/probes/verovio/` — 25 node scripts (`exp01`–`exp21`
  from the review, `exp22` from the critic pass) + `results.txt`;
  `sh docs/probes/verovio/run-all.sh` regenerates it from any cwd against
  `app/node_modules/verovio` (4.5.1). The substrate doc cites scripts by
  name (`exp12` = key signature not applied to sounding pitch, `exp09` = no
  auto-beaming for MEI, `exp11` = ties in the timemap, `exp20`/`exp21` =
  SVG determinism and toolkit option leakage, `exp10` = hit-testing).
- **Highest-impact finds** (either would have shipped through every gate):
  Verovio does not apply the key signature to sounding pitch (every F♯ in G
  major would have been assessed as F♮); Verovio does not beam MEI input;
  the timemap lists tie-stop notes as onsets; ULID ids are neither
  deterministic nor NCNames; the taxonomy's rhythm, syncopation, meter and
  hands ladders were mis-ordered against every graded syllabus; the
  original calibrator rule let only focus dimensions rise and any dimension
  fall, and counted its own edge probes as failures.
- **Decisions parked for Nick (ratify by merging, or steer post-hoc):** the
  L1–L10 preset table is ABRSM-anchored from memory and marked provisional;
  system marks are virtual projections (never `annotations` rows) — a
  deliberate narrowing of "one persistence path"; `attempts` carry no soft
  delete (void instead); the matcher is a client-executed run (PV1 grows a
  completed-run body).
