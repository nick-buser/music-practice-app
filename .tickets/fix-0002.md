## Problem

`.woodpecker/docker.yml` had a single `when:` block combining
`event: push` + `branch: main` + a `path.include` filter. Path filters need a
diff to match against, and a manual trigger has none, so every workflow is
filtered out and Woodpecker returns the whole pipeline as
`status: error` / `"pipeline definition not found"`.

Hit for real on 2026-08-29: the ops-0001 registry secrets were finally set,
and there was then no way to build the images. `POST /api/repos/42/pipelines`
returned 204 (nothing created) and `wp restart` on pipeline 6 errored with
`pipeline definition not found`. No app change was pending, so the only
options were a fabricated no-op commit or this fix.

## Fix

Two OR'd `when:` conditions — the push rule keeps its path filter, plus a
bare `event: manual` rule with no path filter.
