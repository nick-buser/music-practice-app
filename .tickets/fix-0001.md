## Description

Unplanned micro-ticket surfaced by feat-0001's gate run: `buildHeatmap()`
in `app/src/data/sounddata.ts` mixed local-time math (`getDay`/`setDate`)
with UTC rendering (`toISOString`), so in any non-UTC timezone the grid's
first cell can be a UTC Monday — failing the `starts on a Sunday` invariant
in `sounddata.test.ts`. Never caught because CI never ran (repo joined the
forge today). Fix: all grid arithmetic in UTC.
